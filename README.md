# 📔 오늘의 기록

간단한 메모장 / 일기 웹앱입니다. 설치할 것도, 회원가입도 없습니다.

## 쓰는 법

`index.html` 파일을 더블클릭해서 브라우저로 열면 끝입니다.

## 기능

- 글 쓰기 / 수정 / 삭제
- 날짜와 기분(이모지) 기록
- 제목·내용 검색, 월별로 묶어 보기
- 입력을 멈추면 1.5초 뒤 자동 저장
- `Ctrl + S` (맥은 `Cmd + S`)로 바로 저장
- 밝은 화면 / 어두운 화면 자동 전환
- 휴대폰 화면에서도 잘 보임

## 지난 글은 잠겨서 열립니다

왼쪽 목록에서 지난 글을 고르면 **읽기 전용**으로 열립니다. 실수로 글자를
눌러도 내용이 바뀌지 않고 저장도 되지 않습니다.

| 상황 | 버튼 |
|---|---|
| 새 글 쓸 때 | `저장` |
| 지난 글 읽을 때 | `수정` · `닫기` · `삭제` |
| 고치는 중 | `저장` · `취소` |

- **수정** — 이때부터 고칠 수 있습니다
- **닫기** — 빈 종이로 돌아갑니다 (`Esc` 키도 같습니다)
- **취소** — 고치기 전 내용으로 되돌립니다
- **저장** — 저장하면 다시 잠깁니다

고치던 중에 다른 글을 열거나 닫으려 하면 한 번 더 물어봅니다.

## 알아두기

글은 **지금 쓰는 브라우저 안에**만 저장됩니다(localStorage).

- 다른 컴퓨터나 다른 브라우저에서는 안 보입니다.
- 브라우저 방문 기록·사이트 데이터를 지우면 함께 지워집니다.
- 시크릿 모드에서는 창을 닫으면 사라집니다.

## 파일 구성

```
index.html   앱 전체 (화면 + 기능이 이 파일 하나에 다 들어있음)
README.md    이 설명서
```
