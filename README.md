# 오늘의 기록

비밀번호와 9점 잠금 패턴으로 여는 개인 일기장 웹앱입니다.
기록은 여는 사람의 브라우저 안에서 암호화되어 보관됩니다.

## 어디에 무엇이 있나

```
web/                  배포용 웹앱 (이 폴더를 그대로 올리면 동작)
  index.html          앱 전체 — 빌드 과정도, 외부 의존성도 없음
  diary.html          본문 원본 (Artifact와 공유하는 소스)
  manifest.webmanifest, sw.js, icon-*.png
  README.md           올리는 방법
build-web.py          diary.html 을 index.html 로 감싸는 스크립트
ogq_market/           카카오 이모티콘 → 네이버 OGQ 규격 변환 결과물
scripts/              위 변환 스크립트
```

## 웹앱 쓰는 법 · 올리는 법

`web/README.md` 를 보세요.

## 기능

- 글 쓰기 / 수정 / 삭제, 날짜·시간·기분 기록
- 제목·내용 검색, 월별 묶어 보기
- 지난 글은 읽기 전용으로 열려 실수로 고쳐지지 않음
- 비밀번호로 잠금 (PBKDF2 + AES-256-GCM), 15분 방치 시 자동 잠금
- 비밀번호를 잊으면 잠금 패턴으로 열고 새 비밀번호를 정함
- 휴대폰·PC 화면에 맞춰지는 배치, 밝은/어두운 화면 자동
- 홈 화면에 추가하면 앱처럼 열리고, 인터넷 없이도 동작

## 주의

비밀번호와 잠금 패턴을 **모두** 잊으면 기록을 되살릴 방법이 없습니다.
서버에 열쇠가 없기 때문입니다. 가끔 `내보내기`로 백업을 받아 두세요.
